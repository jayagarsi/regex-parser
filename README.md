# regex-parser

This repository contains the implementaion of a parser and engine for regular expressions. The code is completely implemented in C++, and there is an executable version generated with Web Assembly in [my website](https://jayagarsi.github.io/projects/regex-parser/). For more information on how it is implemented one can go to the [```docs```](./docs/) folder.

## Get Started

To execute the code it is only necessary to have C++ installed. I used C++14, so any version equal or above should work too. Then, it is enought to execute the Makefile with the ```make``` command. This will generate only one executable ```main``` that can be executed directly in Linux. 

In the ```docs``` folder you can find more information on how the implementation works on a higher level. In ```src``` you have all the files with the different class headers and implementations. You will also see a ```wasm_binding.cpp``` and a ```build.sh```. This are strictly reserved for generating the Web Assembly files. The ```test``` folder has a ```.cpp``` file to execute a small battery of tests and check if the code works properly. Lastly, the ```webass``` folder holds a ```.zip``` with files necessary for the web assembly and a guide on how to execute it.

## Code Organization

There are three classes in this repository:

- ```Parser```: this class is in charge of parsing the regular expression strings into an Abstract Syntax Trees (AST) which preserves precedence order of operations. This is implemented as a recursive-descent parser based on the grammar in [```src/regex.g4```](./src/regex.g4). 
- ```AutomataManager```: this takes as input an AST tree generated by the previous parser and traverses it to generate a Non-Determenistic Automata (NFA). For now, the code only implements an NFA and simulates it to check if an arbitrary string is accepted by it. In a future, DFAs will also be implemented.
- ```RegExParser```: this last class works as an interface between the first two and the user. It gives a set of functinos to generate the parse trees, hidding the logic to the sure, while also giving methods to print the trees.
